# Integration tests

Run integration tests from the repository root against a standalone `xrpld` node.
Follow the [integration-test setup in CONTRIBUTING.md](../../../../CONTRIBUTING.md#integration-tests)
for the Docker image, configuration mount, build and test commands.

The shared configuration is [`.ci-config/xrpld.cfg`](../../../../.ci-config/xrpld.cfg).
For amendment updates, see [Updating the Docker container for CI](../../../../CONTRIBUTING.md#updating-the-docker-container-for-ci).
For browser tests, follow the [browser-test instructions](../../../../CONTRIBUTING.md#browser-tests).
